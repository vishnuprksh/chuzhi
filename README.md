# v0 Workspace Prototype

A local, interactive prototype of a v0-style AI website builder. It includes a chat workspace, prompt-driven preview variations, project history and search, model and quality controls, responsive preview sizes, code view, and a sample storefront.

## Run locally

```sh
npm install
npm run dev
```

Use `npm run build` for a production build and `npm run lint` to run Oxlint. Prompt generation is simulated locally; it does not call an AI service or deploy a real website.
